영차영차 등반대 — 턴제 클라이밍 퍼즐 (v2)

파일
- index.html : 화면/스타일
- rules.js   : 규칙 엔진 + BFS 솔버 (힌트·파 자동 계산)
- stages.js  : 10개 스테이지 데이터 (여기만 고치면 새 스테이지 추가)
- game.js    : 렌더링, 연출, 사운드(WebAudio 합성), 저장(localStorage)

핵심 규칙
- 체력(최대 5): 저그·볼륨 +1, 핀치·슬로퍼·사이드풀·언더클링 −1, 포켓 −2, 크림프는 타이밍(PERFECT −1/GOOD −2/MISS −3). 0이 되면 낙하.
- 균형(−2~+2): 좌우로 크게 이동하면 기울고, 위로 곧게 오르거나 발판을 디디면 돌아옴. 끝까지 기울면 이동마다 체력 −1.
- 슬로퍼는 균형 가운데일 때만, 사이드풀은 기울어 있을 때만, 언더클링은 발판을 밟고 있을 때만.
- 손이 발판보다 30% 이상 높아지면 발이 떨어짐.
- 별: ⭐ 완등 / ⭐⭐ 꿀단지 전부 / ⭐⭐⭐ 꿀 전부 + 파 이내 (파는 솔버가 계산, GOOD 기준 → PERFECT로 파보다 적게도 가능)
