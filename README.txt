- 한 홀드에 두 손발이 겹치는 이동 금지
- 발 디딤 방향으로 골반이 미세하게 따라가되 모든 고정 접점 유지
- 이동 성공 시 약 285ms 동안 곡선 보간하여 손발을 옮김
- 기존 정면 얼굴, 실루엣, 벽 및 홀드 그림 재사용
- 새 이미지 없음. 기존 파일 별도 수정 없음

참고: 기존 코스보다 홀드 간격과 손발 도달 범위가 달라진 테스트 버전입니다.
